隱私權政策

崇昇運動事業股份有限公司 — CS Real 粉絲專頁自動化系統

本隱私權政策說明崇昇運動事業股份有限公司（以下簡稱「我們」）在您授權使用 Facebook Graph API 相關自動化服務（包含但不限於自動貼文、留言回覆管理，以下簡稱「本服務」）時，如何處理相關資訊。

一、收集與存取的資訊

  • 粉絲專頁權限：經您授權的存取權杖 (Access Token)，用於執行貼文發佈與讀取互動紀錄。
  • 公開互動內容：您授權管理之粉絲專頁上的公開留言、按讚狀態及貼文內容。
  • 系統操作紀錄：執行自動化任務的時間、對象及執行結果。

二、資訊的使用目的

我們存取上述資訊僅用於以下開發與管理目的：

  • 執行自動化貼文發佈與排程功能。
  • 自動回覆粉絲專頁留言以提升互動效率。
  • 管理員身分識別與權限驗證。
  • 改善系統穩定性與自動化邏輯。

我們不會將存取到的任何資料用於廣告、行銷、或出售給第三方機構。

三、資料儲存與安全

  • 存取權杖 (Token) 加密儲存於受保護的伺服器環境中。
  • 資料傳輸全程使用 HTTPS 加密，符合 Meta 數據使用政策要求。
  • 僅限授權之系統管理員可進行技術維護。

四、用戶權利與資料刪除

您可以隨時透過 Facebook 的「設定與隱私」>「設定」>「商務整合」來撤銷本應用程式的授權。 一旦授權撤銷，我們將立即失去存取您粉專資料的權限。若需請求刪除系統內的歷史操作紀錄，請聯繫管理員。

五、聯繫我們

若對本政策有任何疑問，請透過 CS Real 官方管道或與管理員「頭目」聯繫。
